# 👥 Customer Segmentation using Unsupervised Learning

## 📌 Overview

This project applies Unsupervised Machine Learning techniques to segment customers into meaningful groups based on purchasing behavior.

## 🎯 Objectives

- Analyze customer data
- Perform feature engineering
- Reduce dimensionality using PCA
- Cluster customers using K-Means
- Generate business insights

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🤖 Algorithms Used

- StandardScaler
- PCA
- K-Means Clustering

## 📊 Evaluation

- Elbow Method
- Silhouette Score
- Cluster Profiling

## 📈 Workflow

1. Data Cleaning
2. Feature Engineering
3. Exploratory Data Analysis
4. PCA
5. K-Means Clustering
6. Cluster Visualization
7. Business Recommendations

## 📂 Files

- `Customer_Segmentation_using_Unsupervised_Learning.ipynb`

## 🚀 Outcome

Successfully segmented customers into distinct groups to support targeted marketing strategies and business decision-making.
