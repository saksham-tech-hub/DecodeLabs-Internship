# 🛡️ E-Commerce Fraud Risk Detection using Machine Learning

## 📌 Overview

This project develops a Machine Learning pipeline to detect fraudulent e-commerce transactions using supervised learning algorithms.

## 🎯 Objectives

- Analyze transaction data
- Perform data preprocessing
- Train multiple ML models
- Compare model performance
- Detect fraudulent transactions

## 🛠️ Technologies Used

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 🤖 Models Used

- Logistic Regression
- Decision Tree
- Random Forest
- XGBoost 


## 📊 Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

## 📈 Workflow

1. Data Cleaning
2. Exploratory Data Analysis
3. Feature Engineering
4. Model Training
5. Model Evaluation
6. Performance Comparison

## 📂 Files

- `E-Commerce Fraud Risk Detection using Machine Learning.ipynb`

## 🚀 Outcome

Built a fraud detection model capable of identifying suspicious transactions with strong predictive performance.
